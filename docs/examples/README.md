# 标准示例：全功能触发问题 + 配色参考图

这个目录保存仓库的「标准示例」：一条能覆盖系统全部核心能力的输入问题，以及配套的配色参考截图。可用作回归验证、功能演示或 README 演示素材。

## 示例问题（research 模式 + 附带 `palette-reference.png` 附件）

```text
帮我构建一个「团队周报生成器」：支持录入工作项（类型：开发/测试/文档/会议/学习；
字段：负责人、耗时小时、一句话备注），数据用 localStorage 持久化；统计视图支持
「按人员」「按类型」两个维度切换并带合计行；支持上周/本周切换与空状态引导；
最后可一键生成纯文本周报并复制到剪贴板。界面走现代深色风格，配色参考我上传的
截图，功能要完整真实，页面细节和注释尽量丰富。
```

## 各功能触发对照

| 能力 | 触发点 |
|---|---|
| 研究子 agent | research 模式进入时自动委派，独立上下文产出需求简报 |
| 附件多模态 | 粘贴/上传 `palette-reference.png` → vision 模型读图注入构建上下文 |
| ReAct 循环 | think → act → observe 全程时间线 |
| HITL 权限确认 | 首次 `write_file`（ask 级）弹确认卡片，点「允许并记住」验证会话内授权 |
| 静态校验 + 自修复 | `run_checks` 抓问题 → 模型用 `edit_file` 精准修复 → 复检 |
| 浏览器实测 | `run_checks` 附带 chromedp 实测（环境无 Chrome 时静默降级并留痕） |
| 上下文压缩 | 复杂产物 + 多轮修复使轨迹超阈值时触发「已自动压缩历史消息」 |

## 使用方式

1. 打开工作区页面，模式切换为 `research`。
2. 直接把 `palette-reference.png` 拖入或 `Ctrl+V` 粘贴到输入框（粘贴上传功能见 commit `fe102cd`）。
3. 粘贴上方示例问题并发送，观察轨迹中各能力依次触发。

## 备注

- `build` / `plan` / `research` 三种模式互斥，本示例走 `research`；想覆盖 plan 两阶段门控，可另用 plan 模式提问（如 Conway 生命游戏类需求）。
- 构建完成后在预览区「继续修改」输入条发送修改指令（如「把周报导出格式改成 Markdown 表格」）可触发 refine 迭代路径。
